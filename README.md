# 昇腾 AI 处理器实操教程

面向后端程序员的华为昇腾（Ascend）平台入门与动手指南。读者基线：熟悉 C++、Java、Python，写过服务、调过性能、读过日志，对大模型结构、深度学习框架和 AI 加速卡的计算方式没有系统了解。

教程围绕一条主线展开：一段计算从 Python 或 C++ 代码出发，经过框架、运行时、驱动，落到昇腾 AI 处理器上执行，再把结果和耗时带回来。每一章都给出可直接运行的命令或完整工程代码，并用后端系统里已有的概念做对照。

全教程统一使用「昇腾 AI 处理器」或「NPU」指称计算卡本身，使用「Device」指称一张卡及其上下文环境。各章首次出现的专业名词都有白话解释，完整的对照表列在下方术语速查表。

分章文件在 `chapters/` 下。每章按「本章目标 → 先说结论 → 核心概念 → 动手实操 → 常见坑 → 自测题 → 答案 → 参考来源」组织，命令与代码可整段复制。单文件阅读版在仓库根目录执行 `python3 scripts/build-fullbook.py` 本地生成；改动章节后执行 `python3 scripts/check-chapters.py` 做结构与风格自检。

### 卡时怎么算

卡时是云端算力的计量单位，$1\ \text{卡时} = \text{NPU 卡数} \times \text{使用小时数}$。100 卡时可选单卡用 100 小时，或 8 卡用 $100 \div 8 = 12.5$ 小时。核时同理，$1\ \text{核时} = \text{vCPU 数} \times \text{使用小时数}$，720 核时在 16 vCPU 规格下折 45 小时。环境开机即消耗额度，关机停止；CANNLab 的 `/mnt/workspace` 与 `/home` 关机后保留，删除环境后清除。口径来自 CANNLab 用户指南。

### 没有卡也能跑：CPU 仿真

CANN Toolkit 自带 cannsim（后续更名 npusim，CANN 提供的性能仿真命令行工具），在 x86_64 或 aarch64 的 Linux 上模拟 Ascend 硬件的计算单元、存储层级与调度行为，只需安装 toolkit，无需驱动、固件与算子包。官方 Ascend C 样例的 `run.sh` 支持 `run-mode=cpu`，在普通服务器上验证算子功能与精度，`run-mode=npu` 才需要真卡。

仿真可完成算子编译、功能验证、精度比对，并输出指令流水图。仿真耗时与真机不同，性能结论需回到真卡测量。macOS 没有原生仿真包，用 arm64 Ubuntu 容器承载 CANN Toolkit 即可，当前 Apple Silicon 机型可直接运行这类容器。参考：[无卡仿真流程](https://gitcode.com/org/cann/discussions/289)、[CPU 仿真模式说明](https://developer.huawei.com/home/forum/ascend/thread-02200221708716711299-1-1.html)。

### 最小成本起步路线

1. 注册 AtomGit 账号并完成实名认证，登录 CANNLab 领 100 卡时与 720 核时。
2. 在 CANN 组织下任一项目点「CANNLab → 云开发」，创建 A2 单卡环境，用 WebIDE 或本地 VSCode 的 Remote-SSH 连接。
3. 先跑 `npu-smi info` 与第 2 章的校验脚本，确认设备与 CANN 版本；云环境跳过驱动与固件安装步骤。
4. 按第 3、4、5 章顺序动手，代码放 `/mnt/workspace`，用完关机。
5. 第 8 章先在 CPU 环境用 cannsim 或 `run-mode=cpu` 验证逻辑，再到 NPU 环境编译与计时。
6. 第 7 章需要多卡时使用 8 卡规格，或按小时租 2 至 8 卡实例。
7. 卡时耗尽后走积分商城兑换，或转为按小时租用。

## 术语速查表

表中解释按后端工程师的既有经验给出，先读这一张表，再进入正文。各章首次出现这些词时仍会复述一次说明。

| 术语 | 全称或英文 | 一句话解释 |
|------|-----------|-----------|
| NPU | Neural Processing Unit，神经网络处理单元 | 专门执行矩阵与向量计算的处理器，本教程中指昇腾 AI 处理器 |
| Host | 主机侧 | 运行业务进程和操作系统的一段，通常是 CPU 与内存 |
| Device | 设备侧 | 一张昇腾 AI 处理器及其显存、计算单元，由 Host 上的进程管理 |
| CANN | Compute Architecture for Neural Networks | 华为提供的异构计算软件栈，位于驱动与上层框架之间 |
| AscendCL / ACL | Ascend Computing Language | CANN 对外提供的 C/C++ 编程接口，用来管理设备、内存、执行流和模型 |
| Runtime | 运行时 | CANN 中负责把 Host 下发的任务排到设备上执行的那一层 |
| Driver | 驱动 | 内核态模块，让操作系统能访问并管理物理卡 |
| Stream | 执行流 | 设备上的一条任务队列，队列内按提交顺序执行，队列间可并发 |
| Event | 事件 | 记录在流中的时间点，用于计时和跨流等待 |
| 算子 | Operator / OP | 一次具体计算，如矩阵乘、加法、激活函数，等价于框架里的一个函数 |

| AICore | AI Core | 芯片内的计算核心，内含矩阵计算单元与向量计算单元 |

| MindIE | Mind Inference Engine | 华为面向昇腾的推理引擎，负责模型加载、调度与服务化 |

| KV Cache | Key-Value Cache | 生成式推理中缓存历史注意力中间结果，避免重复计算 |
| Prefill / Decode | — | 生成式推理的两个阶段：处理整段输入，以及逐个产出新 token |
| TP / PP / DP | Tensor / Pipeline / Data Parallelism | 三种切分方式：切一层内的矩阵、切模型的层、切训练数据 |
| DDP | Distributed Data Parallel | 各卡持有完整模型、分摊数据并同步梯度的训练方式 |
| token | — | 模型处理文本的基本单位，可粗略理解为切分后的词片段 |
